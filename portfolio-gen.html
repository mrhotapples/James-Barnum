Portfolio Gen

Add a piece to the portfolio. This tool copies any files you upload into the right folder and adds the entry to portfolio-data.js. Using the same title and category again updates that piece.

This browser can't write to your folder directly (use Chrome or Edge for that). Download mode is on: load your current portfolio-data.js so the new piece gets added to the existing list. You'll download the updated file plus any uploads and drop them into your site folder.
